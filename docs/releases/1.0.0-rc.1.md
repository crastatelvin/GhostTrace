# GhostTrace 1.0.0-rc.1 (release candidate)

This is a **release candidate**, not the final 1.0.0. It is staged as a draft
prerelease so the release rehearsal and the remaining platform gates can run
against the actual artifacts. Linux x86_64 is the only platform with
build-and-run evidence.

## What this candidate contains

- the native CLI (`ghosttrace`) and desktop workbench (`ghosttrace-desktop`);
- safe folder capture, coverage ledger, manifest verification, and
  coverage-aware diff;
- JSONL, syslog, journal-export, Chromium/Firefox history, and EVTX import
  through bounded adapters, with risky parsers isolated in a worker;
- indexed timeline, phrase search, event detail, scoped entities, bounded
  relationships, five compiled rules, notes and saved views;
- redacted HTML/JSON/CSV reports and verifiable packages;
- encrypted Ed25519 manifest signing and explicit key trust;
- portable backup/restore and schema migration with a pre-migration backup;
- shell completions, offline guides, tracked synthetic samples, a CycloneDX
  SBOM, and build information.

Nothing is uploaded and no URL found in an artifact is fetched. The optional
read-only localhost API is not part of this candidate.

## Install and verify

```bash
sha256sum -c ghosttrace-1.0.0-rc.1-<target>.tar.gz.sha256
tar -xzf ghosttrace-1.0.0-rc.1-<target>.tar.gz
./ghosttrace-1.0.0-rc.1-<target>/bin/ghosttrace --version
./ghosttrace-1.0.0-rc.1-<target>/bin/ghosttrace-desktop --version
```

When the release workflow attests provenance:

```bash
gh attestation verify ghosttrace-1.0.0-rc.1-<target>.tar.gz \
  --repo crastatelvin/GhostTrace
```

The binaries are **unsigned**. Platform installer signing (Apple notarization,
commercial Windows signing) is separate and optional; evidence signing uses a
local key and an explicit fingerprint list.

## Known issues and open gates

- **Windows and macOS are not verified.** Code paths exist but no native build,
  terminal smoke, or screen-reader run is claimed. Do not use this candidate as
  a Windows/macOS support statement.
- **Live NVDA, VoiceOver, and Orca runs are open.** Automated `egui_kittest`
  accessibility tests pass; they are not a substitute for a screen-reader
  session. Windows Terminal/macOS terminal smoke checks are also open.
- **CLI annotation arrived after this candidate was built.** `ghosttrace
  annotate record/history` was added on `main` after the tag; the packaged RC
  binaries predate it. Notes, tags, and dispositions remain append-only
  revisions; saved views are still desktop-only.
- **The 10 GiB / 100,000-file capture corpus was run on this host only.** A
  combined 1M-event + 100,000-file run (9.72 GiB captured, ext4) and a
  capture-only run over exactly 10,737,400,000 bytes (10.0 GiB) completed on
  Linux x86_64; Windows/macOS were not measured; see `docs/performance.md`.
- **1M-event ingest is 5,150 events/s** on the reference host's tmpfs
  profile, not the original 25,000/s target; the same build on this host's
  ext4 SSD measures 2,019 events/s, so the narrowed target names the
  filesystem.
- **`wgpu` was rendering-verified once, on software Vulkan.** Glow remains
  the default; hardware-driver and Windows/macOS `wgpu` coverage is unverified.
- **Unsigned installers** may trigger OS warnings; verify the checksum/source.
- **No legal certification, hardware acquisition guarantee, or universal
  parser/OS compatibility** is implied.

## Reproduce the rehearsal

Use the tracked samples in the archive (or repository) with the commands in
`docs/walkthrough.md`, `samples/README.md`, and `docs/cli.md`. The synthetic
data contains no real accounts, hosts, paths, or evidence.
