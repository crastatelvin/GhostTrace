# GhostTrace 1.0.0-rc.2 (release candidate)

This is the second **release candidate**, not the final 1.0.0. It exists because
the first candidate's packaged binaries predated three changes on `main`; a
published tag is never moved, so this candidate re-cuts the artifacts from the
current tree. Linux x86_64 is the only platform with build-and-run evidence.

## What changed since 1.0.0-rc.1

- **Desktop appearance.** A token-based palette system (`theme.rs`), app bar,
  status bar, cards, stat tiles, and status chips across all seven screens. The
  state machine, worker boundaries, and every control label are unchanged.
- **`ghosttrace annotate record|history`.** Analyst notes, tags, and finding
  dispositions from the CLI, append-only, with conflict detection. A bookmark
  is the recorded `bookmark` tag on an event.
- **Documentation.** A rewritten top-level README with captured screenshots,
  badges, and architecture diagrams; the 10 GiB capture-corpus and `wgpu`
  renderer records.
- **No schema change.** The case schema version is still 5; cases created by
  rc.1 open unchanged.

## What this candidate contains

- the native CLI (`ghosttrace`) and desktop workbench (`ghosttrace-desktop`);
- safe folder capture, coverage ledger, manifest verification, and
  coverage-aware diff;
- JSONL, syslog, journal-export, Chromium/Firefox history, and EVTX import
  through bounded adapters, with risky parsers isolated in a worker;
- indexed timeline, phrase search, event detail, scoped entities, bounded
  relationships, five compiled rules, notes, tags, dispositions, and saved
  views;
- redacted HTML/JSON/CSV reports and verifiable packages;
- encrypted Ed25519 manifest signing and explicit key trust;
- portable backup/restore and schema migration with a pre-migration backup;
- shell completions, offline guides, tracked synthetic samples, a CycloneDX
  SBOM, and build information.

Nothing is uploaded and no URL found in an artifact is fetched. The optional
read-only localhost API is not part of this candidate.

## Install and verify

```bash
sha256sum -c ghosttrace-1.0.0-rc.2-<target>.tar.gz.sha256
tar -xzf ghosttrace-1.0.0-rc.2-<target>.tar.gz
./ghosttrace-1.0.0-rc.2-<target>/bin/ghosttrace --version
./ghosttrace-1.0.0-rc.2-<target>/bin/ghosttrace-desktop --version
```

When the release workflow attests provenance:

```bash
gh attestation verify ghosttrace-1.0.0-rc.2-<target>.tar.gz \
  --repo crastatelvin/GhostTrace
```

The binaries are **unsigned**. Platform installer signing (Apple notarization,
commercial Windows signing) is separate and optional; evidence signing uses a
local key and an explicit fingerprint list.

## Known issues and open gates

- **Windows and macOS are not verified.** Code paths exist but no native build,
  terminal smoke, or screen-reader run is claimed. Do not use this candidate as
  a Windows/macOS support statement.
- **Live NVDA, VoiceOver, and Orca runs are open.** Automated `egui_kittest`
  accessibility tests pass; they are not a substitute for a screen-reader
  session. Windows Terminal/macOS terminal smoke checks are also open.
- **`wgpu` was rendering-verified once, on software Vulkan.** Glow remains the
  default; hardware-driver and Windows/macOS `wgpu` coverage is unverified.
- **1M-event ingest is 5,150 events/s** on the reference host's tmpfs profile,
  not the original 25,000/s target; the same build on this host's ext4 SSD
  measures 2,019 events/s, so the narrowed target names the filesystem.
- **Unsigned installers** may trigger OS warnings; verify the checksum/source.
- **No legal certification, hardware acquisition guarantee, or universal
  parser/OS compatibility** is implied.
